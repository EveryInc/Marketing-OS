# Marketing OS Smoke Rubric

Run these five cases after a change to the Marketing OS root, routing, collaboration,
knowledge boundaries, or learning loop.

## Pass rule

A run passes only when all five cases:

- Load the listed skill paths and only the task-relevant references.
- Exhibit every expected behavior in the response or artifact.
- Produce zero hard failures.
- Preserve facts, protected language, open questions, and human approval gates.
- End in a usable decision or handoff rather than a generic summary.

Record the case ID, output reference, expected behaviors observed, hard failures, and
verdict. A polished answer with one hard failure does not pass.

## Learning rule

When a smoke case catches an observed regression, capture the narrow failure mode as a
regression-test candidate. Do not rewrite the whole skill around one failed phrasing.
