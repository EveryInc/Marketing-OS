# Cases

This directory is reserved for the rare project case whose evidence remains necessary
to understand a reusable Marketing OS rule.

Cases are optional study material. No skill loads them by default, and no current
decision may cite a case as authority without re-verifying the underlying facts.

Do not add a case when the reusable rule stands on its own. Git history preserves
deleted project artifacts. If a case and a skill disagree, the skill governs the
workflow and the current ruled project source governs project facts.
