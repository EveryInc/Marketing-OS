# Web — Landing Page

Writes landing page copy — hero, value propositions, social proof, and CTAs for conversion-focused pages.

## When to invoke

- When building a landing page for a new product, campaign, or launch
- When a launch skill orchestrates channel execution and needs the landing page deliverable
- When writing or rewriting a standalone conversion page

## Dependencies

- `foundation/marketing-os`
- `brand-voice/{relevant brand}` (loaded dynamically)
- `positioning/{relevant brand}` (loaded dynamically)
- `craft/copywriting`
- `craft/editing`

Brand is resolved dynamically based on what invokes this skill.

## Channel-specific notes

- Scannable hierarchy: headline → subhead → proof → CTA in seconds
- Single conversion goal per page — every element serves one action
- Above-fold copy does the heaviest lift; below-fold substantiates

## Offer and sale pages

For a sale page, gift page, upgrade page or any page a promotional email points to, read
`references/offer-page.md` before drafting. It sets the research to do first, the block
order, what to leave out, the length, and how to hand over the copy.

The short version:

- Open three live pages of the same kind and look for test data before writing a word.
- Use the offer-page order: banner, price card, one button, what's included, steps,
  questions, fine print.
- Name features; do not describe them. About 200 words.
- Deliver every string on the page in one block, in page order, with no commentary inside it.
