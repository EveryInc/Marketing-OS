# Offer and sale pages

An offer page sells one offer to someone who already knows the product. It is the shortest
page a brand writes. Use this file for sale pages, gift pages, upgrade pages and any page a
promotional email or banner points to.

## Before writing

1. **Look at live pages first.** Open at least three live offer pages of the same kind
   (same offer type, comparable audience) and write down the order of their blocks and how
   each states the price. If a page will not open, ask for a screenshot before drafting.
   Never imitate a page from memory of its "style".
2. **Look for test data.** Search for experiments and benchmarks on the specific choices the
   page has to make: how the price is shown, how the bonus is framed, how long the page is.
   Say which findings rest on one source and which on more.
3. **Pull the brand's own past results** for the same kind of offer when a tool can reach
   them. They outrank outside data.
4. **Hand the findings over with the draft**, each one tied to the line it changed. If a
   finding changed nothing, say so.

If the person asking has requested research, the research comes before the first draft, not
after the third revision.

## The order of an offer page

This is the order seen on established subscription offer pages. Start from it. Depart from
it only for a stated reason.

1. **Banner.** A headline and one line that states the offer and the bonus.
2. **Price card.** Plan name, the price in its smallest honest unit (per week or per month),
   the regular price struck through, and a line saying what is charged today. If a bonus
   comes with the plan, tag it inside the card.
3. **One button**, with one line of terms under it: when the offer ends and how to cancel.
4. **What's included.** A short list. The bonus goes first. Each item is a name and one
   short line.
5. **How it works**, in three numbered steps, when the offer has a mechanic the buyer must
   act on (a gift, a referral, a claim).
6. **Questions.** Five or fewer, each answered in one or two sentences.
7. **Fine print.** Regular prices, renewal, eligibility, end date.

## What does not belong

- A long essay on the campaign idea. A short "why" section is different and does belong
  when the buyer may not know the product: a heading, then two short paragraphs. The first
  says who the product is for and what it gives them. The second says what this offer adds.
  It sits above the list of what's included.
- A description of each product feature. Name the features and stop. Feature copy belongs on
  the product page and in the emails.
- A second offer. If another audience needs a different offer, one line in the questions
  sends them to their own page.
- Any price comparison the page then has to explain. If two regular prices exist (monthly
  and yearly), the card uses one and the fine print states both.

## Length

About 200 words of reader-facing copy. If the draft passes 250, something from "What does
not belong" is in it.

## Voice on a short page

Plain copy still needs the brand's character. With so few words, put it where the eye lands:
the label above the headline and the button. One line of wit in one of those slots is enough.
A page with none reads as a template.

## Delivering the copy

- Deliver **every string on the page, in page order, in one block**: the banner on other
  pages that links to it, the page banner, the card, the button, each list item, each step,
  each question and answer, the fine print.
- No commentary inside the block. Notes on what changed, and why, come after it and only
  when they are wanted.
- When asked a follow-up about one string ("what does the banner say"), answer it and then
  put that string into the full block. The next full version must contain every answer given
  along the way.
- Carry the editor's own lines forward unchanged.

## What went wrong the first time this page type was written here

Recorded so the same draft is not produced again.

- **No reference pages and no test data before drafting.** The first draft was built from
  internal rules and product facts alone. The research was done only after the editor asked
  why it had not been.
- **An invented structure.** The draft used its own section headings, an explainer block and
  a long questions list, in place of the banner, card, button, included, steps, questions,
  fine print order that offer pages use.
- **Feature descriptions on an offer page.** Each product got a sentence. The reference page
  names its benefits in three or four words each.
- **The price was a sentence, not a card.** No small unit, no struck-through price, no
  "charged as" line.
- **Imitating a page that could not be opened.** Asked to match a reference page that would
  not load, the writer drafted from a general impression of the brand. The right move was to
  ask for a screenshot at once.
- **The deliverable arrived in pieces.** The banner was answered in one message, the page in
  another, with tables and notes mixed in. The editor had to ask three times for all the
  copy in one place.
- **A measurement made after the claim.** Reading level was cited as a reason to change the
  copy before it was measured. Measured, the first draft already passed. Measure first.
- **Flat voice.** The editor's own changes added the page's only wit, in the label and the
  button.
- Left out the "why" section on the second page of a set after the editor had added one to
  the first. Read the editor's live version again right before writing each new page, and
  mirror every section they added. If the live document no longer shows the page, ask for it.
