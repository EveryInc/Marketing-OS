# Test Reality

Decide what a test can read before writing variants.

## Rules

- **Volume first.** Estimate clicks and conversions per variant from budget and expected
  cost per click. Practitioner guidance is roughly 50 conversions and $300–500 per variant
  before judging a creative ([Segwise](https://segwise.ai/blog/facebook-ad-creative-testing-best-practices)).
- **Underpowered means directional.** Below that, call results directional in the plan and
  the readout. Do not name a winner.
- **Angles before words.** Small tests can only show large differences, so test distinct
  angles. Wording tests need volume (strong: wording features barely predict winners).
- **Fewer variants at low budget.** Each extra variant splits the same clicks. Two per group
  is the floor for any comparison.
- **Winners can flip.** In large news datasets, rerun winners flipped about a quarter of the
  time. Confirm a winner with a second run before promoting it.
- **Judge downstream.** Compare signups and early engagement (open rates, activation) by ad,
  not clicks alone (`marketing-science/measurement`).
- **Use the first test to set a baseline.** When no target cost exists, the first run's cost
  per conversion becomes the provisional target for the next.

## Readout template

- Spend, impressions, clicks, conversions by ad
- Cost per click and cost per conversion by ad
- Early engagement by ad's cohort
- Directional or decisive, and why
- What the next test should change
